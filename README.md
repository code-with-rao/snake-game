# snake-game
🐍 Snake Game – Android Application
📌 Project Description
The Snake Game Android Application is a classic arcade-style game developed using Android Studio. The player controls a snake that moves around the screen, eats food, grows in length, and scores points. The game ends when the snake collides with itself or the game boundary.

This project demonstrates basic Android game development concepts, including game loops, touch input handling, canvas drawing, and collision detection.

🎯 Features
🎮 Classic snake gameplay

🍎 Snake grows longer after eating food

📈 Score increases with each food eaten

❌ Game over when snake hits itself or boundary

🔄 Restart game option

📱 Smooth touch or button-based controls

⚡ Lightweight and fast performance

🛠️ Technologies Used
Language: Java

IDE: Android Studio

Minimum SDK: Android 5.0 (API 21)

Graphics: Canvas & Paint

Game Logic: Custom game loop

▶️ How to Run the Project
Install Android Studio

Open Android Studio → Open an existing project

Select the SnakeGame folder

Let Gradle sync complete

Connect an Android device or start an emulator

Click Run ▶️

🎮 How to Play
Use on-screen buttons / swipe gestures to move the snake

Eat the food to increase score and length

Avoid hitting:

The snake’s own body

The screen boundaries

Try to achieve the highest score
