# 🐍 Snake Game – Android Application

A classic **Snake game** built as an Android application using **Android Studio**.

The player controls a snake that moves around the screen, eats food, grows, and scores points. The game ends when the snake collides with itself or the boundary of the play area — just like the classic Snake game many of us loved on earlier mobile phones.

---

## 📌 Features

- 🎮 **Classic snake gameplay** — control with touch or swipe
- 🍎 **Food collection** to grow the snake and increase score
- 📈 **Score tracking**
- ❌ **Game over** when bumping into walls or the snake’s own body
- 🔄 **Restart** option to play again
- ⚡ Smooth, responsive performance

---

## 🛠️ Tech Stack

- **Platform:** Android
- **Language:** Java
- **IDE:** Android Studio
- **Build System:** Gradle
- **Minimum SDK:** Android 5.0 (API 21)
- **Graphics:** Canvas & Paint
- **Game Logic:** Custom game loop
